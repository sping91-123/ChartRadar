# 반복 알림과 근거 없는 후보 안내 개선

## 문제와 변경

- 청산 압력은 같은 상태에서도 최소 간격만 지나면 재발송됐다. 최근 24시간의 마지막 알림을 기준으로 압력 10점 이상 상승, 매우 높음 단계 진입, 쏠림 방향 변경이 없으면 반복을 막는다. 기존 최소 3시간 간격은 유지한다. 24시간이 지나면 지속 상태를 다시 알릴 수 있다. 이는 알림 빈도 정책이며 위험 예측의 정확도를 뜻하지 않는다.
- 청산 알림에 위험이 커지는 방향, 제공되는 롱/숏 계정 비중, 추정 압력, 확인할 가격 반응을 표시한다. 추정 점수는 실제 청산 규모나 발생 확률로 표현하지 않는다.
- 경제 일정은 발표 1시간 이내에 같은 시각의 지표를 한 번에 묶어 알린다. 이벤트 이름과 시간대 표기가 바뀌어도 실제 발표 시각으로 중복을 차단하며 기존 발송 기록에도 적용한다. 오래된 일정 응답은 알림에서 제외한다.
- 하루 최대 일정 알림 제한이 실제 최근 24시간 발송 기록을 보도록 고친다.
- 코인 후보의 알림 본문에 실제 감지된 근거와 다음 확인 시간대를 담는다. 개인화 과정에서 이 내용을 일반 문구로 덮어쓰지 않는다. 점수와 발송 품질 기준은 유지한다.
- 새 알트 후보 알림은 종목과 시간대를 선택한 분석 화면으로 연결한다. 기본 목록에 없는 유효한 형식의 종목도 선택을 유지하며, 기존 분석 사용량과 Pro 권한은 그대로 적용한다. 화면은 현재 분석이며 알림 당시의 스냅샷을 보존하는 기능은 아니다.

## 검증

- `npm.cmd run test:push-usefulness`: 반복 압력 억제와 실제 변화 허용, 일정 묶음·표기 차이·기존 기록 중복·시간 창·오래된 데이터·일일 제한, 후보 근거 보존, 안전한 종목·시간대 연결.
- `npm.cmd run test:push-entitlements`: 전체 스캐너가 최근 하루를 조회하는지와 기존 권한 경계를 검사한다.
- `npm.cmd run test:push-candidates`, `npm.cmd run test:push-targets`, `npm.cmd run smoke:billing`.
- 위 회귀 검사, `npm.cmd run build`, `git diff --check`는 통과했다. 빌드 중 확인된 Set 순회 대상 호환 오류는 `Array.from`으로 수정했다.
- 외부 Chrome의 모바일 화면에서 기본 목록 안/밖 종목과 알림 시간대 선택, 가로 넘침과 콘솔 오류를 확인했다. 브라우저의 분석 사용량 거절 응답은 검사 전용 fixture로 제공하며 실제 계정의 사용량은 쓰지 않는다.
- 운영 배포 후 새 코드의 자동 스캔과 화면 연결을 추가 확인한다.
- 알림 수신이나 유료 가치가 입증됐다고 모의 검사만으로 단정하지 않는다.
