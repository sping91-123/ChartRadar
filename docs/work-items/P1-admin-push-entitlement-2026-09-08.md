# 관리자 계정의 일반 Pro 푸시 권한 수정

## 문제와 수정

일반 푸시 스캐너가 구독 행만으로 권한을 판정해, 별도 유료 구독 행이 없는 관리자를 Basic으로 처리했다. 이제 서버 Auth의 신뢰된 `app_metadata.role`과 기존 구독 원장을 함께 사용한다.

- 계정 삭제 대기/처리/실패, 삭제된 계정, 사용자 ID 불일치는 발송 대상에서 제외한다.
- Auth 및 삭제 상태 조회가 실패하면 발송을 중단한다. 각 요청에는 5초 제한을 적용한다.
- 사용자 편집 가능한 metadata는 권한 근거로 사용하지 않는다.
- Basic, 시장별 구독, 만료 및 회수 경계를 유지한다.
- 시장 조건, 점수, 확정봉, 감시 만료, 알림 선택, 중복 및 빈도 제한은 변경하지 않는다.

## 검증과 배포

- `npm.cmd run test:push-entitlements`: 관리자 발송과 Basic 차단, 신뢰된 역할, 시장별 권한, 만료/회수/삭제/조회 실패 회귀 검사 통과. 모의 FCM을 사용한다.
- `npm.cmd run test:push-targets`, 기존 entitlement matrix, `npm.cmd run smoke:billing`: 통과.
- `npm.cmd run build`: production build 및 타입 검사 통과.
- `git diff --check`: 통과.
- 수정 커밋 `3350b21`의 원격 일치 및 운영 배포 완료를 확인했다.
- 운영 모바일 Home·알림 설정 진입, 가로 넘침 없음, 브라우저 오류 없음, health 및 snapshot 응답을 확인했다. 비로그인 Pro 상세와 관리자/크론 접근 보호를 유지한다.
- 운영 자동 검사에서 관리자 권한이 반영되는 것을 확인했다.

## 검증의 범위

권한 수정 배포와 자동 검사 실행을 확인한 상태다. 운영 발송 실패에 대한 추가 진단과 해당 휴대폰의 실제 수신 확인이 남아 있으므로 전체 푸시 정상화를 완료했다고 표현하지 않는다. 계정·기기별 운영 기록은 공개 문서에 포함하지 않는다.
