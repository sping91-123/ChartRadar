# 첫 유료 결제까지 30일: 제품과 운영의 고정 기준

기준일: 2026-09-06 KST. 목표 기한: 2026-10-06 23:59 KST. 대표 승인에 따라 2026-09-07 KST에 운영 배포까지 완료했다.

## 결정과 범위

첫 대상은 BTC·ETH를 보지만 계속 차트를 확인하기 어려운 사용자다. `현재 상태 → 기다릴 조건 → 무료 감시 1개 → 알림 당시 판단 확인 → 여러 조건이 필요하면 Coin Pro`로 첫 경험을 연결한다. 다른 시장은 보조 동선으로 유지한다. 가격(월 29,000원), 적격 계정 14일 체험, 결제·권한 검증, 공식 방향 계산과 Basic/Pro 데이터 경계는 유지한다.

## 변경하지 않을 완료 기준

1. 새 방문자는 로그인 없이 첫 화면에서 앱의 목적과 무료 시작 버튼을 본다. 버튼 한 번으로 현재 시장에 진입한다. 기존 계정·선호 시장 복귀가 유지된다.
2. 홈과 선물의 우선순위는 상태, 위험, 기다릴 조건, 감시 행동이다. 이유·전문 분석보다 감시 행동이 앞선다. 저장 후 재진입하면 기존 감시로 연결된다. 오래된 데이터로 새 감시를 만들지 않는다.
3. Pro는 실제 구매 버튼 전에 무료/유료 차이를 간단히 보여준다. 누구나 이용 흐름을 조작해 볼 수 있고, 예시는 가상임을 명시한다. 체험 적격 여부·자동 갱신·해지를 숨기지 않는다. 기존 구매·복원·오류 처리 경로를 사용한다.
4. 알트는 직접 선택한 종목 분석을 먼저 본다. 보조 시장 자료는 필요할 때 펼친다. 글로벌은 판정부터, 복기는 필수 3개 입력부터 보여준다. 필수 판단 조건을 접어 숨기지 않는다.
5. 360px/390px에서 가로 넘침, 하단 내비게이션 가림, 로그인 후 복귀 손실이 없다. 예시 조작은 실제 감시·결제·성과 이벤트를 만들지 않는다. 유료 안내 노출은 실제 화면에 나타난 때만 집계한다.

## 측정 정의

- 최종 결과: 테스트·내부 계정을 제외한 스토어 검증 실제 유료 결제 사용자 1명 이상. 무료 체험, 구매 버튼 클릭, 클라이언트 구매 성공 이벤트를 결제로 세지 않는다. 실제 매출·통화·환불 상태는 스토어/서버 원장으로 확인한다.
- 선행 지표: 신규 이용자의 첫 감시 저장, 체험 시작. 조건이 실제 발생하지 않은 것은 실패로 간주하지 않는다. 앱 재방문과 조건 발생 후 재확인을 구분한다.
- 보호 지표: 구매 실패/권한 반영 지연, stale 상태에서 감시 시도 차단, 중복 감시 방지, Basic 민감 데이터 미노출.
- 이전 관찰 기준은 P1-normalization 문서에 있다. 신규 가입 7일 1명이라는 관찰은 유입 부족 신호다. 표본이 작으므로 전환율 목표·실패 원인을 통계적으로 확정하지 않는다. 14일 체험 종료 전 사용자는 유료 전환 분모에 넣지 않는다.
- 코호트 v2는 NOT_STARTED 상태를 실제 모집 전에 바꾸지 않는다. 기존 conversion-health 보고서는 관찰용이며 유료 매출 원장을 대체하지 않는다.

## 검증 결과

### 로컬 구현 및 검증

- 시작 로그인 화면을 가치 설명과 무료 시작으로 교체. 한 번의 클릭으로 홈 진입하며 기존 로그인/선호 시장 복귀 로직을 유지했다.
- 홈의 일정 카드를 판단 아래로 이동. 선물은 감시 버튼을 근거보다 앞에 두고 전문 설명·차트를 펼쳐 보는 구조로 바꿨다. 기존 무료 감시 1개, Pro 20개, source/snapshot/hash 복귀와 중복 방지는 유지했다.
- Pro는 무료/유료 비교를 실제 구매 버튼 전에 배치하고 중복 소개·기능·계정 카드를 접었다. 가상 이용 예시 3단계와 조건 미충족 사례는 실제 이벤트/성과로 기록되지 않는다. 체험 적격·가격·자동 갱신·해지는 구매 버튼 주변에 유지한다.
- 알트는 종목을 선택하기 전 상세 분석 API를 요청하지 않는다. BNB도 명시적으로 선택할 수 있고 종목 URL·새로고침·Pro 복귀를 연결했다. 시간대/관점/민감도 설정과 긴 읽기 안내를 접었다. 동일 종목 반복 조회의 서버 일일 사용량 중복 방지 정책은 유지된다.
- 현물 우선 후보는 중복 없이 최대 3개, 각 카드에 무효화/리스크와 관심 코인 연결을 함께 표시한다. 글로벌 판정 뒤의 긴 근거는 펼쳐 본다. 뉴스는 공식 사건 이후 판단 변화가 목적임을 표시하고 수집 통계는 접었다.
- 복기는 제목·종목·다음 확인 기준을 먼저 입력한다. 방향·결과·원칙·메모는 선택 입력이다. 입력하지 않은 손익을 0R로 만들지 않고 `기록 대기`로 저장한다.
- CoinProConversionLink의 gate 노출은 IntersectionObserver로 링크의 50% 이상이 화면에 들어온 때 기록한다. 단순 마운트만으로 노출을 만들지 않는다. 과거 노출 데이터는 보정하지 않으며 배포 전후를 구분해야 한다.
