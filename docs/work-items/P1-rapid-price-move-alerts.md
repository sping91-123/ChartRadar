# BTC·ETH 급등락 알림과 당시 차트

## 문제와 변경

가격이 크게 움직였다는 알림을 눌러도 발생 시점의 차트와 확인할 가격을 찾기 어려웠다. BTC·ETH의 확정 1분봉으로 급등락을 감지하고, 변동률·직전 가격 범위·당시 차트를 하나의 알림 기록에 보존한다. 기록 화면의 다음 행동은 해당 종목의 현재 분석 보기다.

## 감지와 발송 정책

| 자산 | 5분 변동률 절댓값 | 15분 변동률 절댓값 |
| --- | --- | --- |
| BTC | 1% 이상 | 2% 이상 |
| ETH | 1.5% 이상 | 3% 이상 |

- Binance USDT 무기한 선물의 1분봉을 매분 확인한다. 위 수치는 초기 운영 기준이며 예측 성능을 입증한 값이 아니다.
- 시세 접근 지역이 달라지는 것을 막기 위해 `vercel.json`에서 감지 함수를 싱가포르로 명시한다. route의 선호 지역 선언만으로 단일 지역 실행을 보장하지 않는다. 시세 HTTP 실패 상태도 운영 진단에 남긴다.
- 미완성 봉, 누락·중복·순서 오류가 있는 봉, 잘못된 OHLC, 2분보다 오래된 자료는 발송 후보에서 제외한다. 현물 가격으로 대체하지 않는다.
- 두 시간 조건을 동시에 만족하면 기준 대비 변동이 큰 조건 하나를 선택한다.
- 같은 종목·방향은 5분 안에 반복 발송하지 않는다. 이후 30분까지는 직전 알림 가격에서 해당 종목의 5분 기준만큼 더 움직여야 다시 보낸다. 반대 방향 전환은 따로 평가한다.
- 실패한 발송 시도도 짧은 반복을 제한하는 기록에 포함한다. 같은 이벤트를 여러 실행이 동시에 처리하면 기존 계정·이벤트 고유 제약으로 한 실행만 발송권을 얻는다.
- 원본 차트를 먼저 저장하고 FCM에 전송한다. 휴대폰이 늦게 연결됐을 때 오래된 급등락 알림이 쌓이지 않도록 짧은 TTL을 적용한다.
- 발송 도중 실행이 중단된 같은 이벤트는 자동 재발송하지 않는다. 저장·발송은 분산 트랜잭션이 아니므로 중복 억제와 수신 보장을 동일시하지 않는다. FCM 성공, 휴대폰 도착, 사용자의 열람은 서로 다른 검증 단계다.
- 조용한 시장에서는 시세 요청만 수행한다. 후보가 있을 때 등록 기기와 구독을 읽고 기존 Pro 권한·탈퇴 상태·시장 및 알림 선택을 확인한다. 계정별 동시 처리 수를 제한하며 기존 스캐너와 같은 기기 조회 상한을 적용한다. 대규모 사용자 처리는 별도의 분할 발송 설계가 필요하다.

## 화면과 설정

- 코인 알림 설정에 `BTC·ETH 급등·급락`을 추가하고 발송 기준을 표시한다.
- 새 기본 설정에는 포함하며 기존에 저장한 사용자의 알림 선택은 유지한다. 기존 사용자는 새 항목을 직접 켜야 해당 기기로 발송된다.
- 알림 링크는 계정에 저장된 해당 이벤트 하나만 조회한다. 로그인하면 원래 기록으로 돌아오며, 자료가 없으면 현재 차트로 대체하지 않고 안내와 재시도를 제공한다.
- 보존한 확정 1분봉, 감지 가격·시각, 변동 전 30분 고가·저가, 분당 평균 거래량 비교를 표시한다. 원본 봉은 FCM 페이로드에 넣지 않는다.
- 알림 당시 화면은 당시 관측값이며 현재 가격과 다를 수 있다. 확인 가격을 향후 지지·저항이나 매매 지시로 설명하지 않는다.
- 천 단위 가격 통과 알림은 이번 변경에 포함하지 않는다.

- `npm.cmd run test:rapid-price-move`: 자산별 기준, 두 시간 조건 선택, 잘못된 입력·지연 거절, 원본 복원, 반복 제한, 동시 예약, 발송 실패 상태, 권한·선호, 읽기 전용 스캔, 계정 경계 및 cron 인증.
- `npm.cmd run test:push-targets`, `npm.cmd run test:push-usefulness`, `npm.cmd run test:push-entitlements`, `npm.cmd run test:push-candidates`, `npm.cmd run smoke:billing`.
- `npm.cmd run build`, `git diff --check`.
- 외부 Chrome 모바일 화면에서 상승·하락 기록, 현재 분석 링크, 잘못된 주소, 누락 기록 재시도, 로그인 복귀, 새 설정 항목 및 가로 넘침을 확인한다. 인증·기록을 대체한 화면 검증과 실제 인증 거절 응답을 구분한다.
- 실제 시세 응답 및 운영 cron 실행 여부를 확인한다. 자연 발생 알림의 휴대폰 수신과 결제 가치는 배포 또는 모의 시험 통과만으로 확정하지 않는다.
