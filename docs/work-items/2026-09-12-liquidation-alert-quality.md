# 청산 알림의 변화·가격 근거 연결

## 문제와 변경

동일한 청산 경고가 24시간 뒤 반복되고, 알림을 눌러도 당시 근거 대신 현재 홈으로 이동했다. 새 알림은 직전 발송과의 점수 변화, 실제 확정봉의 기준 가격, 다음에 확인할 조건을 함께 제공한다.

- 마지막 확정 15분봉을 그 직전 네 봉의 고가·저가와 비교한다. 관측 가격을 확정 지지·저항이나 진입 지시로 표현하지 않는다.
- 새 원본 화면은 알림 당시 점수·변화·봉·가격·시각을 보존한다. 현재 분석은 별도 버튼으로 연결한다. 이미 받은 구형 푸시의 주소는 바뀌지 않는다.
- 직전 성공 발송은 24시간 밖의 기록과 legacy payload.sentCount까지 조회한다. 같은 방향의 변화 없는 경고는 시간 경과만으로 다시 보내지 않는다.
- 10점 이상 증가에는 60분, 실제 위험 방향 반전·75점 진입에는 15분, 예전 중립/불명 방향에서 방향 확인에는 180분 간격을 적용한다. 기존 권한·기기별 선택은 유지한다.
- 누락·오래된·미래 입력, 불완전한 봉은 차단한다. 펀딩 자료와 15분 자료는 서로 다른 갱신 주기를 적용한다.
- 원본 저장과 unique(user_id,event_key) 선점을 FCM보다 먼저 수행한다. 같은 이벤트는 한 요청만 발송하며 유효기간은 최대 5분이다. sending/failed/partial 상태를 목록과 상세에서 구분한다.
- 미시간대 일정은 한국어로 표시한다. 예상·이전 수치는 원본 지표명과 단위가 같은 단일 그룹의 확인된 값만 사용한다.
- 개인 감시가 없는 홈에서는 조건 설정으로 안내하며, 알림 설정에서 급등·급락 선택 상태를 명시한다. 기존 사용자 설정은 자동 변경하지 않는다.

## 확인 범위와 남은 제한

실제 휴대폰의 자연 수신과 유료 전환을 입증한 검증은 아니다. 기존 가격·상품·결제·권한은 수정하지 않았다. FCM 접수 후 결과 PATCH가 실패하면 sending 기록을 남기고 같은 이벤트의 재전송을 막는다. 결과 복구·부분 성공 기기 재시도·다음 봉의 다른 키까지의 불확실 발송 억제는 이번 변경에 포함하지 않는다. 진정 후 동일 수준으로 재상승하는 별도 위험 구간의 자동 재활성화도 구현하지 않았다.

운영 배포 완료 여부와 실제 배포 SHA·지역·운영 재검증 결과는 이번 작업의 최종 보고 및 배포 증거에 기록한다.

## 운영 확인 후 발송 오류 관측 보완

42eb836 운영 배포의 실제 계정·모바일 검증은 통과했고 모든 임시 계정·기록을 삭제했다. 새 push-cron은 sin1에서 실행됐으며 청산 source 및 조회 오류는 없었다. 전체 발송 실패4는 이전 배포의 두 번의 스캔에도 집계됐지만, 기존 발송 유틸이 이유를 남기지 않아 원인은 확정할 수 없었다.

FCM HTTP 실패의 고정 허용 코드와 HTTP 상태, 인증 실패·전송 실패의 고정 분류만 로그에 남기도록 보완했다. 원문 응답을 throw에도 포함하지 않는다. 토큰·계정·메시지·미등록 코드·잘못된 JSON의 비공개 문자열이 로그나 throw에 포함되지 않는지 `node scripts/test-fcm-failure-diagnostics.mjs`로 검증했다. 성공 응답·실패 throw·재시도 정책과 기기 설정은 유지한다. 운영 CRON_SECRET은 민감 환경변수라 내보낼 수 없으므로 수동 dryRun을 실행했다고 보고하지 않고 자연 스케줄러 로그를 확인한다.
