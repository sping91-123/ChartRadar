# 개인 상황에서 시작하는 조건 감시

## 문제와 결과

같은 시장 알림만으로는 사용자가 왜 다시 확인해야 하는지 알기 어려웠다. 감시를 저장할 때 진입 전 관망, 상승 방향 보유, 하락 방향 보유 중 상황을 함께 보관하고, 이용 가능한 조건의 실제 방향에 맞춰 먼저 보여준다. 시장이 혼조여서 가격 조건이 없으면 없다고 안내한다.

Coin Pro에서는 직접 정한 가격 위·아래에서 15분봉이 마감하는 조건도 생성할 수 있다. 서버가 가격, 방향, 권한, 확정 종가와 이미 충족된 조건 여부를 검사한다. 기존 최대 20개 한도에 포함되며 24시간 또는 1회 충족 시 종료한다. 기존 Basic 보존 정책은 유지한다.

알림은 저장한 상황과 실제 확인된 사실, 다음 확인 기준을 전달한다. 알림 링크에 감시 ID를 포함하고, 소유자에게만 저장 당시와 현재의 판단·가격·위험 차이를 보여준다. 일반 비교는 알림 열람 집계에 넣지 않는다. 원본이 없는 기존 감시에 개인 상황을 추정해 붙이지 않는다.

## 범위와 계약

- 월 29,000원과 14일 체험, 상품 ID 유지.
- 상황과 기준 가격은 감시별 원본으로 보존. 같은 조건 중복 저장은 실제 기존 상황을 반환.
- 사용자 지정 가격은 Pro 생성 기능이며 주문이나 실시간 가격 터치 감시가 아니다.
- 기존 확정봉 평가기, 5분 검사, 중복 방지와 1회성 종료 사용. 새 DB 스키마 없음.
- 현재 상세는 최신 자료만 해석. 목록은 7분 이내 마지막 검사 시점으로 명확히 표시.
- 수익률·적중률·회피 손실·결제 전환은 이 구현으로 입증하지 않는다.
